
# HQ Router Configuration

## 1. Vai trò

HQ Router là Router biên tại Headquarters.

Chức năng:
- Kết nối WAN với ISP.
- Kết nối LAN với CORE-HQ.
- Trao đổi route với CORE-HQ bằng OSPF.
- Thiết lập IPsec VPN đến BR1 và BR2.
- Chuyển tiếp traffic giữa mạng HQ và các chi nhánh.

## 2. Interface Addressing

| Interface | Connected Device | IP Address |
|---|---|---|
| G0/0 | ISP | 200.1.0.2/30 |
| G0/1 | CORE-HQ | 10.255.0.1/30 |

## 3. Basic Configuration

```cisco
enable
configure terminal

hostname HQ-Router
no ip domain-lookup
enable secret HQ-Enable@123

service password-encryption

banner motd # HQ ROUTER - AUTHORIZED ACCESS ONLY #
```

## 4. Interface Configuration

### WAN Interface

```cisco
interface gigabitEthernet 0/0
 description WAN_TO_ISP
 ip address 200.1.0.2 255.255.255.252
 no shutdown
```

### LAN Transit Interface

```cisco
interface gigabitEthernet 0/1
 description TRANSIT_TO_CORE-HQ
 ip address 10.255.0.1 255.255.255.252
 no shutdown
```

## 5. Static Default Route

```cisco
ip route 0.0.0.0 0.0.0.0 200.1.0.1
```

Default Route cho phép HQ Router chuyển traffic không có route cụ thể đến ISP.

## 6. OSPF Configuration

```cisco
router ospf 1
 router-id 1.1.1.1
 network 10.255.0.0 0.0.0.3 area 0
 default-information originate
```

OSPF chỉ chạy trên liên kết transit giữa HQ Router và CORE-HQ.

`default-information originate` quảng bá default route xuống CORE-HQ khi Router có default route hợp lệ.

## 7. IKE Phase 1 Configuration

```cisco
crypto isakmp policy 10
 encryption aes 256
 hash sha
 authentication pre-share
 group 5
 lifetime 86400

crypto isakmp key VPN@12345 address 200.1.1.2
crypto isakmp key VPN@12345 address 200.1.2.2
```

## 8. IPsec Phase 2 Configuration

```cisco
crypto ipsec transform-set TS-VPN esp-aes 256 esp-sha-hmac
```

## 11. Crypto Map

```cisco
crypto map VPN-MAP 10 ipsec-isakmp
 set peer 200.1.1.2
 set transform-set TS-VPN
 match address 110

crypto map VPN-MAP 20 ipsec-isakmp
 set peer 200.1.2.2
 set transform-set TS-VPN
 match address 120
```

Apply Crypto Map to WAN interface:

```cisco
interface gigabitEthernet 0/0
 crypto map VPN-MAP
```

## 12. Save Configuration

```cisco
end
write memory
```

## 13. Verification

```cisco
show ip interface brief
show ip route
show ip ospf neighbor
show crypto isakmp sa
show crypto ipsec sa
show crypto map
show access-lists
```

## 14. Troubleshooting

| Vấn đề | Kiểm tra |
|---|---|
| Không ping được ISP | WAN IP, subnet mask, cable, interface |
| OSPF không FULL | Transit IP, OSPF Area, interface |
| IKE không hình thành | Peer IP, PSK, IKE Policy |
| IPsec không hình thành | Transform Set, Crypto ACL |
| Không truy cập được chi nhánh | Routing, VPN selector, return path |
